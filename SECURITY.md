# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.

Contact the project maintainers privately through GitHub's repository security advisory reporting feature:
https://github.com/aboudwebs/al-euro/security/advisories/new

Include the affected component, impact, reproduction steps, and any relevant logs or proof of concept. Do not include real customer data, credentials, access tokens, or production secrets.

We will acknowledge reports as soon as practical and coordinate a fix and disclosure timeline with the reporter.
