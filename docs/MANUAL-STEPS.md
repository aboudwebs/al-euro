## 0) ⚠️ لا تنشر الخادم قبل ربط MsgPlus

رموز التحقق صارت **عبر MsgPlus SMS فقط** (لا واتساب/Green API ولا Firebase SMS). إن نُشر الخادم قبل ضبط متغيرات `MSGPLUS_*`:
- «نسيت كلمة المرور» عبر الرمز وتغيير رقم الهاتف سيردّان بـ 503/رسالة «الخدمة غير متاحة» (لا يُخزَّن أي رمز ولا يُرسَل شيء).
- التسجيل برمز التحقق يبقى معطلاً أصلاً (`REGISTRATION_OTP_ENABLED=false`).
- تسجيل الدخول العادي لا يتأثر.

### ما أحتاجه من MsgPlus (لم أتمكن من فتح وثائقهم الرسمية فلم أخترع أي API)
من لوحة/وثائق MsgPlus الرسمية: (1) عنوان https لإرسال رسالة واحدة، (2) طريقة المصادقة (اسم الترويسة وقيمتها)، (3) أسماء الحقول المطلوبة في الطلب (رقم المستلم، النص، المرسِل)، (4) صيغة الرقم المطلوبة (9639XXXXXXXX أو +963… أو 09…)، (5) كيف يدل الرد على نجاح الإرسال، (6) اسم المرسِل (Sender ID) المعتمد، (7) بيئة اختبار إن وُجدت.

### متغيرات Render (الخدمة `al-euro`) — أسرار، لا تُوضع في الكود
| المتغير | المعنى |
|---|---|
| `MSGPLUS_API_URL` | عنوان https للإرسال |
| `MSGPLUS_BODY_TEMPLATE` | JSON بأسماء حقول MsgPlus، مثال شكلي: `{"to":"{{to}}","text":"{{message}}","from":"{{sender}}"}` — الأسماء الحقيقية من وثائقهم |
| `MSGPLUS_AUTH_HEADER` / `MSGPLUS_AUTH_VALUE` | ترويسة المصادقة وقيمتها (سر) |
| `MSGPLUS_SENDER` | المرسِل |
| `MSGPLUS_PHONE_FORMAT` | `international` (الافتراضي) أو `plus` أو `local` |
| `MSGPLUS_CONTENT_TYPE` | `json` (الافتراضي) أو `form` |
| `MSGPLUS_SUCCESS_FIELD` / `MSGPLUS_SUCCESS_VALUE` | اختياري: حقل في الرد يجب أن يساوي قيمة معينة |
| `OTP_DAILY_CAP` | اختياري: سقف الرسائل اليومي (الافتراضي 500) |

**اختبار بعد الضبط:** من حسابك أنت فقط وبرقمك أنت: «نسيت كلمة المرور» ← يصل الرمز خلال دقيقة، صالح 10 دقائق، 5 محاولات، استخدام واحد. لا تجرّب بأرقام مستخدمين.

## 2) متغيرات Render الأخرى
| المتغير | القيمة | متى |
|---|---|---|
| `TOTP_ENC_KEY` | `openssl rand -base64 32` | قبل تفعيل 2FA لأي أدمن |
| `REGISTRATION_OTP_ENABLED` | اتركه `false` | `true` فقط بعد نجاح اختبار MsgPlus |
| `ADMIN_2FA_DISABLED` | لا تضبطه | طوارئ فقط (ضياع هاتف الأدمن) |
| `ADMIN_PASSWORD_RESET_TOKEN` + `ADMIN_PASSWORD_RESET_EXPIRES_AT` | رمز عشوائي 32+ حرفاً + تاريخ انتهاء ISO خلال 24 ساعة | لإعادة تعيين كلمة مرور الأدمن مرة واحدة، واحذفهما بعدها |

لا تغيّر `AUTH_SECRET`.

## 3) توافق وسلوك بعد النشر
- الجلسات الحالية تبقى صالحة (التوكن بلا إصدار = 0).
- تُبطَل كل الجلسات القديمة عند: تغيير كلمة المرور/الهاتف، «تسجيل الخروج من كل الأجهزة»، إيقاف/تفعيل الحساب، تفعيل/تعطيل 2FA للأدمن (يبقى الأدمن الحالي مسجّلاً).
- «الخروج من كل الأجهزة» يحذف أيضاً رموز الإشعارات لذلك الحساب.
- كلمات المرور الجديدة 8 أحرف على الأقل؛ القديمة تعمل وتُرقَّى تلقائياً عند أول دخول ناجح.
- **سياسة الإيصال:** إيصال شام كاش مرتبط بطلب لا يُقبل لطلب آخر **حتى لو أُلغي الطلب الأول**. العميل يرفع إيصال تحويل جديداً. (لا يكشف إعادة ترميز لقطة الشاشة — حد معروف.)
- الرفع (الطلبات، الطلبات الخاصة، صور القطع) يُرفض إن تجاوز 6MB قبل قراءة المحتوى (413).

## 4) التحقق بخطوتين للأدمن (F-03)
1. اضبط `TOTP_ENC_KEY` وانشر. 2. لوحة الإدارة ← «الأمان» ← إعداد، أضف المفتاح لتطبيق مصادقة، أدخل الرمز، **احفظ رموز الاسترداد الثمانية**. 3. لا يُفرض على أي أدمن قبل أن يُنهي إعداده. 4. ضياع الهاتف: رمز استرداد، أو الطوارئ `ADMIN_2FA_DISABLED=true` مؤقتاً.
